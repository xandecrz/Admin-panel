# 🚀 Admin Panel Dashboard

Un panel administrativo moderno desarrollado con **HTML5**, **CSS3** y diseño responsivo. 
Este proyecto está pensado para servir como base para sistemas de gestión empresarial, inventarios, ventas, reportes y administración de usuarios.

## 📸 Vista Previa

![Admin Dashboard](img/admin.PNG)

## ✨ Características

- 📊 Dashboard con resumen de información.
- 💰 Módulo de Ventas (Sales).
- 📦 Gestión de Inventario.
- 🔧 Área de Mantenimiento.
- 📢 Sección de Marketing.
- 🧾 Módulo de Contabilidad.
- 📈 Reportes Administrativos.
- ⚙️ Configuración del sistema.
- 🔍 Barra de búsqueda integrada.
- 👤 Perfil de usuario administrativo.
- 📱 Diseño adaptable y fácil de personalizar.

## 🛠️ Tecnologías Utilizadas

- HTML5
- CSS3
- Diseño Responsive
